# Case: c-runtime/controller

The runtime bytes for the widest fixture: two Real parameters, a String
parameter, a Real/Integer input port, and mixed-type outputs.

## Artifacts

- `Controller_Controller_fmi.cpp`
- `Controller_Controller_hooks.h`
- `Controller_Controller_model.cpp`

**Conversion**: SysML v2 architecture -> C interface headers -> C++17 FMI 2.0
CoSimulation runtime plus the user-owned model hook file
**Requirement / fault**: the plumbing must be fully generic over the nine value
references; a hard-coded variable name, a missing null-handle guard, a Boolean
stored as `int`, or a String setter that aliases `std::string` to `char*` is a
fault the golden makes visible
**Level**: component; the generated translation unit is the unit under test
**Input**: `tests/fixtures/controller/controller.sysml`
**Expected**: one `Controller_Controller_Handle`, a parameter-only switch over
the VR enum, eight typed get/set functions that validate the whole batch before
writing, the CoSimulation status and event functions, nine `fmi2Error`
placeholders for the unsupported state/derivative calls, and a model file whose
`do_step` returns `fmi2Error` with a TODO while `initialize` and `terminate`
return `fmi2OK`
**Independent oracle**: `g++ -std=c++17 -fsyntax-only` for every generated
translation unit, and the linked harness `tests/c_runtime_harness.cpp`, which
drives the public FMI API and checks the GUID, type, causality, parameter phase,
Boolean/String round-trips, and step-time bookkeeping
**Comparison**: byte-for-byte against the golden text
**Normalization**: none; the generator reads no clock, path, or environment
value, and the model file is deterministic on creation
**Volatile fields**: none
**Update policy**: `UPDATE_GOLDENS=1 python -m pytest
tests/test_c_runtime.py`; never under `CI`
**Notes**: the three `fmi2/` copies are not goldens; the test compares them
byte-for-byte against `pyfmi_interfaces.fmi2_headers()`. The generated C headers are
the existing `tests/golden/c-headers/controller/` artifacts, regenerated by the
same command.

## What this case proves

That the runtime carries every primitive and causality of a realistic component
without naming a variable in its plumbing, and that the generated model file is
an honest placeholder rather than a silent success.
